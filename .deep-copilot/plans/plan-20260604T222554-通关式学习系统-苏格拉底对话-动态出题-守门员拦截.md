# 通关式学习系统 — 苏格拉底对话 + 动态出题 + 守门员拦截

> Generated by Deep Copilot · Plan mode
> 2026-06-04T14:25:54.297Z

## 目标 / Goal
将 DeepRead-v2 从被动阅读工具升级为通关式学习系统：实现费曼-苏格拉底对话引擎（拒绝喂饭、基于用户画像定制类比、每轮反问）、基于分层记忆的动态章节通关测试API（5道难度递进单选题）、以及前端守门员弹窗（≥80%通过才放行、未通过则注入指定复习消息到 ChatPanel 并将用户锁在本章）。

## 方案 / Approach
三线并行开发：后端（Prompt 重写 + quiz_service 新建 + 两条新端点）、前端（QuizModal 组件 + ReadPage 拦截逻辑 + ChatPanel 系统消息注入）。后端全程不接触数据库，凭 profile.json 的 core_memory 和 episodic_memory 做个性化；前端使用 portal + Zustand store 做弹窗与 chat 通信。

## 步骤 / Steps
1. **Task1a: prompts.py 新增苏格拉底 Prompt** — 在 prompts.py 末追加 SOCRATIC_CHAT_SYSTEM_PROMPT 模板（含占位符 {book_name}/{core_memory}/{episodic}/{chapter_context}），核心铁律4条：拒绝喂饭、费曼类比（按行业定制）、苏格拉底反问收尾、随时纠偏逻辑漏洞。
2. **Task1b: chat_service.py 新增 Socratic 对话函数** — 在 chat_service.py 新增 stream_socratic_chat(book_name, message, api_key) 函数：读取 profile.json → 格式化 core_memory → 注入系统 prompt → SSE 流式返回。温度设为 0.8、max_tokens 512。
3. **Task1c: master_router + 前端 ChatPanel 对接 Socratic 端点** — 在 master_router.py 新增 POST /api/chat/socratic 端点，入参为 {book_name, message}，调用 chat_service.stream_socratic_chat 返回 SSE。前端 ChatPanel 的 sendAction 需要新增 action_type="socratic" 分支。
4. **Task2a: 新建 quiz_service.py 动态出题引擎** — 新建 quiz_service.py：实现 generate_chapter_test(book_name, chapter_path, api_key) → 读取章节正文 → 读取 profile.json(core_memory + episodic_memory) → 调用 LLM 生成5道难度递进单选题 → 返回 JSON 数组 [{question, options:{A,B,C,D}, answer, explanation}]。温度 0.6，严格 JSON 输出。
5. **Task2b: master_router 新增 Quiz 端点** — 在 master_router.py 新增 POST /api/quiz/generate_chapter_test，入参 {book_name, chapter_path}，调用 quiz_service.generate_chapter_test。
6. **Task3a: 新建 QuizModal.tsx 守门员弹窗** — 新建 QuizModal.tsx：每题一屏、进度条、即时判分。≥80%显示彩带动画+通关金卡+自动下一章按钮；<80%显示未通过提示+关闭弹窗+通知 ReadPage 向 ChatPanel 注入系统消息。使用淡入动画和 confetti 效果。
7. **Task3b: ReadPage 拦截逻辑 + BottomNav 简化** — 修改 ReadPage.tsx 的 handleChapterNavigate：当 readingMode===intensive 时，先 fetch 题目 → 弹出 QuizModal → 按通过/未通过行走两个分支。通过：正常执行 onNavigate；未通过：调用 chatStore.addMessage({role:"system"}) 注入拦截消息，并自动打开 ChatPanel。修改 BottomNav.tsx 移除旧 confirm 占位。
8. **Task3c: api_client.ts 新增请求函数** — 在 api_client.ts 新增 fetchQuizQuestions(bookName, chapterPath) 函数，调用 POST /api/quiz/generate_chapter_test。ChatPanel 的 socratic 模式切换需要新增 POST /api/chat/socratic 调用。
9. **验证: tsc --noEmit + next build + backend health** — TypeScript 编译 + Next.js build + 后端 Docker restart 后健康检查。
