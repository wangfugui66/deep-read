## 目标 / Goal
在 DeepRead-v2 中植入 TeachAny 双入口：TocDrawer 骨架模块旁的「聚合课件」按钮（父级聚合，永不禁用）+ ReaderView 底部的单节 TeachAnyButton（带字数/策略守门员，禁用时引导至父级按钮）。遵守旁路插件纪律：零状态污染、只读数据流、物理隔离。

## 方案 / Approach
双入口设计：TocDrawer 的骨架模块标题旁放置「聚合课件」图标按钮（永远可用，无守门员），负责将整篇/章的子节聚合为宏观课件；ReaderView 底部的 TeachAnyButton 仅针对单节生成（带字数+策略守门员），禁用时引导用户前往父级聚合按钮。

## 步骤 / Steps
1. **创建 TeachAnyButton.tsx 含守门员逻辑** — app/app/components/reader/TeachAnyButton.tsx。Props: bookName, chapterContent (body长度估算字数), chapterStrategy。守门员：wordCount < 1000 或 strategy 为 速读/跳过 → disabled。禁用 tooltip: '本节内容较少，已启动防幻觉保护，请在左侧目录点击【章】层级的按钮生成聚合课件。' 可用 tooltip: '提炼为互动微课件'。onClick 仅 console.log + Toast '后端生成服务对接中…'。使用 GraduationCap 图标。
2. **TocDrawer 骨架模块旁添加聚合课件按钮** — 在 TocDrawer.tsx 的 hasSkeleton 分支中，遍历 tocData.modules，每个 module 条目渲染：module_name + 章节数 + 小型 TeachAny 图标按钮（FoldeOpen 或 Layers 图标）。按钮永远可用（无守门员），onClick 打印 console.log 含 module_name + 子章列表 + Toast '正在聚合整章内容生成大课件…'。
3. **嵌入 page.tsx 单节按钮** — 在 page.tsx 的 ReaderView 与 BottomNav 之间插入 <TeachAnyButton bookName={...} chapterContent={body} chapterStrategy={getChapterStrategy(...)} />。
4. **验证 TS 编译** — npx tsc --noEmit

## 涉及文件 / Affected files

## 风险与缓解 / Risks
- 骨架模块的 module_name 可能与 raw TOC 树的父级节点不完全对应（骨架由 LLM 重组），但聚合按钮基于 skeleton 的 modules 结构，语义上更准确
- TocDrawer 需要导入 TeachAny 图标组件或内联小型按钮，保持 UI 克制不喧宾夺主
- word_count 仍从 body.length 估算；后续应在 ChapterRef 新增字段
