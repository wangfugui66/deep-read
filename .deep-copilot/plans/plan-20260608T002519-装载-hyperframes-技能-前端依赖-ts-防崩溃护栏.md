## 目标 / Goal
装载 HyperFrames 技能库并对齐前端 Web Component 播放架构。安装 @hyperframes/player + GSAP 依赖，确保 TypeScript 类型安全且避免 Next.js SSR 崩溃。

## 方案 / Approach
三步执行：(1) npx skills add 装载官方知识技能，(2) npm install 依赖并确保 package.json 更新，(3) 添加 TypeScript 全局声明以防止 <hyperframes-player> 标签报错。同时承诺后续开发中的 SSR 规避纪律。

## 步骤 / Steps
1. **npx skills add heygen-com/hyperframes** — 在项目根目录执行 npx skills add heygen-com/hyperframes，将官方的 SOP / prompt 技能文件下载到本地 .deep-copilot/ 或等效技能目录中，使后续 AI 生成知识动画 HTML 字符串时遵循官方 @hyperframes 规范（data-start, window.__timelines, GSAP 等）。
2. **npm install @hyperframes/player gsap (with --legacy-peer-deps fallback)** — 在 app/ 下执行 npm install @hyperframes/player gsap。若 React 版本触发 peer dependency 冲突，追加 --legacy-peer-deps。安装后验证 package.json 中 has @hyperframes/player 和 gsap。
3. **添加 TypeScript 类型声明（防编译崩溃）** — 在全局类型声明文件（如 app/global.d.ts 或 app/lib/types.ts）中追加 JSX.IntrinsicElements['hyperframes-player'] 声明，防止未来任何 .tsx 组件使用该标签时触发 TS 报错。
4. **验证：技能文件 + package.json + tsc --noEmit** — 验证 npx skills 是否成功写入技能文件；检查 package.json dependencies；运行 tsc --noEmit 确认 TS 零错误。
