## 目标 / Goal

## 方案 / Approach
创建独立 TeachAnyButton 组件，包含三层守门员（字数 < 1000 禁用 / 策略速读跳过禁用 / 后端未对接仅 Toast），通过 window.open 沙盒隔离；在 page.tsx 的 ReaderView 与 BottomNav 之间单行嵌入，不触碰 Zustand Store。

## 步骤 / Steps
1. **创建 TeachAnyButton.tsx 组件** — app/app/components/reader/TeachAnyButton.tsx — 接收 bookName + chapterContent + chapterStrategy。字数字段从 body.length 估算（ChapterRef 无 word_count）。守门员条件：wordCount < 1000 → disabled；strategy 为 '速读'/'跳过' → disabled。可用时 tooltip='提炼为互动微课件'，禁用时 tooltip='本节内容较少，已启动防幻觉保护，请直接阅读原文'。onClick 仅打印 console.log + Toast '后端生成服务对接中...'。使用 lucide-react 的 GraduationCap 图标。
2. **嵌入 page.tsx 阅读流** — 在 app/app/read/[bookName]/page.tsx 中，ReaderView 与 BottomNav 之间插入 <TeachAnyButton bookName={bookName} chapterContent={body} chapterStrategy={getChapterStrategy(currentChapterPath ?? '')} />。不修改任何现有状态流。
3. **验证 TS 编译** — npx tsc --noEmit 零错误。
